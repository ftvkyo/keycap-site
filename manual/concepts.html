Trees and shapes

A tree is an expression of the coordinates x, y and z, such as hypot(x, y) - 5. A script builds its trees once, as it runs, and fidget evaluates them later, at every point it renders or meshes. A tree’s value at a point is its field there.

A script has one type for trees, Tree, as type_of and error messages name it. Shape in a signature is a Tree read as a solid, negative inside, positive outside and zero on its surface, while Tree is any such value, a number that may vary over space. So any tree can stand for a shape: z - 9 is everything below z = 9. A 2D shape is a tree without z, in the XY plane; see 2D drawings.

This manual calls fidget’s built-ins shapes too, transforms and combinations included, as fidget does. fidget calls their parameters fields, as in field center must be provided for RotateX; anywhere else, a field is a tree’s values.

Types

number
a number that is known when the script runs, such as a count or a size; Rhai keeps integers and floats apart, see Numbers and trees
Tree
a number that may vary over space: a number, or an expression of x, y and z; given only numbers, a function that returns a Tree returns a number, unless its entry says otherwise
Shape
a Tree read as a solid, below 0 inside and above 0 outside
Vec2, Vec3
[x, y] and [x, y, z], of numbers, or vec2 and vec3 values; [x, y] stands for a Vec3 with z = 0 for a point or a direction, or 1 for a scale or a count, but a 3D size needs all three
Axis, Plane
fidget’s axes and planes, see rotate and reflect
Ease
an easing, string | ((t: Tree) => Tree): a name that ease takes, such as "in_out_sine", or a function of t from 0 to 1
Height
number | [number, number]: a height centred on z = 0, or [z0, z1], from z0 up to z1
Sched
a value along a part: a Tree, a function of t, or keyframes in t, as keyframes takes them; t runs from 0 to 1 along the part, from the bottom of an extrusion to its top
string, bool
Rhai’s own

Reading signatures

A function’s description starts with the ways to call it, written as in TypeScript: 

      offset(shape: Shape, d: Tree): Shape
shape.offset(d: Tree): Shape

The notation is:

T[]
an array of T
#{ a: T, b?: U }
a map whose key b may be left out
A | B
either of them
(t: Tree) => Tree
a function, written as a closure, |t| ..., or by name, Fn("name")
name: T = v
an argument that may be left out, v when it is
...input: Shape[]
any number of arguments
shape.f(...)
the method form, its first argument before the dot
type Slice = ...
a name for a type, used by the function it is shown with

Which of fidget’s fields may be left out, and in which order they come, depends on the form of the call; see Calling shapes.

On this site, the strip beside an entry says what it makes; its label says that, and where it comes from.

2D
a shape in the XY plane
3D
a solid
2D to 3D
a solid made from 2D shapes: extruded, revolved, lofted or swept
CSG
shapes combined, offset or hollowed
transform
a shape moved, turned, scaled or mirrored
pattern
copies of a shape
math
numbers and expressions: arithmetic, easings, vectors
script
what a script draws, and where
fidget
fidget’s own, in its viewer and CLI too
keycap
keycap’s, from its prelude or its script API

Units and axes

  • A length is in millimetres: the SVG and DXF exports are in millimetres, and slicers read an STL’s numbers as millimetres.
  • An angle is in degrees, but fidget’s sin, cos and the other trigonometric functions take radians; see Angles in degrees.
  • 2D shapes lie in the XY plane, and the prelude’s round solids and extrusions have their axis along Z.
  • The prelude’s shapes are centred on the origin; see Placement and anchors.

Scripts and files

  • A script shows and exports what it passes to draw, and the value of its last expression is not drawn; see Drawing and colours.
  • The prelude is loaded before every script; its modules load by name, as in import "keycap/screws" as screws;, and other files by their path; see The prelude and Imports.
  • A .keycap script can call everything in this manual, a .fidget script only what fidget’s own tools run; see Dialects.
